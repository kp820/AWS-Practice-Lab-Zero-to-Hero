# ☁️ 50 Days AWS Practice Lab Challenge — Zero to Hero

Welcome to my **50 Days AWS Practice Lab Challenge!** 🚀

This repository documents my hands-on journey of learning Amazon Web Services (AWS) through practical labs, step-by-step implementations, troubleshooting, and project documentation.

My goal is to build practical cloud computing skills and share my learning experience with everyone who wants to learn AWS.

## 🎯 Challenge Objectives

* Gain hands-on experience with AWS services.
* Understand cloud infrastructure and architecture.
* Practice IAM permissions and AWS security.
* Learn automation using AWS Lambda and other AWS services.
* Develop troubleshooting and problem-solving skills.
* Document each lab so other learners can follow along.

## 📚 What You'll Find in This Repository

* Daily lab documentation from Day 1 to Day 50.
* Step-by-step implementation guides.
* AWS CLI commands and configuration examples.
* Architecture explanations and verification steps.
* Troubleshooting notes and key takeaways.
* Practical cloud projects and automation workflows.

## 🚀 How to Use This Repository

1. Open the folder for the day you want to study.
2. Read the lab objectives and requirements.
3. Follow the implementation steps.
4. Run the relevant commands in your own AWS environment.
5. Verify the results and review the key learnings.
6. Clean up resources when appropriate to avoid unnecessary AWS charges.

## 🔐 Security Best Practices

* Never commit AWS access keys, secret keys, passwords, or other credentials.
* Use IAM roles and least-privilege permissions.
* Keep private S3 buckets private.
* Review public-access settings before exposing any resources.
* Check for ongoing AWS charges and delete lab resources when they are no longer needed.
